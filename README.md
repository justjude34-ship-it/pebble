# Pebble

**A quiet companion for the day.**

Pebble sits with a child. Same place every time. No surprises.

- My Day — now, then next
- Feelings — five states, no wrong answer
- Calm — one slow breath, sound off by default
- I Need — six tap-to-speak cards

Local-only. Not therapy. Not a diagnosis. Not crisis care.

Buy once, own forever. Data stays in the browser.
